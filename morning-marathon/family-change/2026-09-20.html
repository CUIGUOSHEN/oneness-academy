与家庭一起改变 · D18：迂回见底，和馅成家

A Lecture Study of Virginia Satir — Session 18 · 期望状态非个体之加总、名词与过程之双向操作、复合等同之迂回法、系统改造之和馅隐喻、软性措辞与二位置换视角

摘　要

本讲收束全书末章第一阶段——收集信息，而启第二阶段之改造。崔老师以一义立其纲：家庭之期望状态，非逐人问得而后相加，乃是系统整体之所欲。全讲以两事为骨。一曰复合等同之用，其法不在直取，而在迂回——客户于某处下不去，便绕道类同之物，由类同而下探其深层结构，复自深层迂回其内心之真实想要；判词「迂回作战或者是曲线救国」是其眼目。二曰改造之的，是系统而非要素，崔老师以「和馅儿」为喻，谓葱花肉韭菜各为其是，必搅于一盆而后成味。末以「我感觉似乎」之软性措辞与二位置换视角收束，示干预之分寸所在。

关键词期望状态（desired state）当下状态（present state）复合等同（complex equivalence）迂回作战一般化系统改造（modifying）和馅儿隐喻二位置换视角标准沟通周期

一系统之期望，非个体之加总

昨日所讲漏斗、漏筛子，其要在收集信息之时不拦截、不筛选、不隔离，方得客户背后之全貌。然收集一事，尚须一「刻意的变化」——邀请客户朝向其期望状态（desired state）而行（00:02:18）。崔老师谓此与 ICF 所倡之成果导向「有一些异曲同工之妙」：欲使客户改变，必先定其内心真实之所欲，而后方能与当下对标，言其一致或不一致。

其对待之词有二：一曰 desired state，理想状态或未来状态；一曰 present state 或 problem state，当下状态或问题状态（00:03:49）。此非名相之争。教练若只问「你要什么」，所得常是一次性之成果；必问「你想成为一个什么样子，且能一直如此」，方触及状态。状态可续，成果可结；续者成场，结者成点。

至 family 之处，则有一大分别，崔老师特为揭出：🟢 崔老师说：「不是每一个人的个体想要做加总……每一个人的内在想要，放到一块做一汇总，或者做一加总，这事儿就算达到了家庭的这个东西呢，不对」（00:04:06）。家庭治疗所求者，是整个家庭作为一个系统所想要达成之结果，而非成员各自所欲之和。盖人之所欲常相冲突，加总所得为零和；系统之所欲则必是共性，是众人共愿一起走到之处。

其探索之问，崔老师举其四：你想为自己和家人做一些什么呢？你希望你和你的家人一起做出一些什么改变呢？如果你能够让自己和家人在某一些方面有些不同，那可能会是发生了一些什么呢？如果有一些魔法发生了，那家庭整个会改变成一个什么效果呢（00:06:38）？四问皆以名词化之形式出之，而皆以「你们一起」为主语。此即「理想状态」之收集法：不问个体之愿，而问共业之相。

二动静相济：删减与总结之双向操作

既欲得其背后，须有工具。崔老师于此揭一总纲：名词化、过程化、删减扭曲总结，皆非固定之招，而是互动过程——视客户之偏而反向施之（00:07:10）。客户一味说名词，如「我挺好」「我需要什么」，则以过程化邀之：「你为什么要用这个呢？」「你如何就可以实现呢？」客户一味讲故事、过于过程化，则邀其收拢、总结，令其名词化。

此一反向施为之理，崔老师括为一句：🟢 崔老师说：「这是我讲了这么多年 NLP 最后给我自己的一个结论……如果客户很静，你就跟他动一动，如果客户很动，你就让他静一静」（00:08:32）。动静相济，是全部手法之底层节律。删减扭曲总结亦然：客户删减扭曲太多，则令其补齐；客户说得过于详尽，则教练代为删减扭曲、总结（00:09:24）。提问本身即可以是删除，亦可以是补全，视其所需而定。

书一百零二页列二法，崔老师释之（00:11:27）。其一，以删减扭曲总结、去名词化、谓指名动词，令客户自见其表达之不一致——明明是名词，何以用过程化出之？其二，寻其希望与期望之物，以引发移置。由是而有一问：教练究竟有无引导？崔老师不讳言之，而界其方向：🟢 崔老师说：「教练引导的方向是朝向客户的理想」（00:11:49）。引导非不可用，所禁者是朝向教练自设之议程。方向既定于客户之理想，引导便只是陪同之手势。

其要尤在具身化（embodiment）。崔老师谓近日常不提此词，而其用实不可缺：令客户设身处地进入其对一事之理解与认知，于具身化之过程中自有所见、有所感（00:12:09）。一百零三页有一要语：第一阶段治疗师做得好之征验，是使客户所言之表层结构与其内在所感之深层结构得一连接（00:13:26）。而用此诸般手法之目的，非为炫技，乃是令其由所择之途径，把散落之个人经历作一整合（00:14:49）。

三迂回作战：复合等同如何绕到底层

既言不一致，须有辨识之法与抵达之法。辨识之例，崔老师举书中 Michelle：「我只是想帮你一把」。单看文字，善意而已；然其声刺耳、双脚分开而立、左手直指对方、右手攥拳抵于右臀（00:22:52）——言与身全然相左。崔老师为之下一定语：🟢 崔老师说：「一就是口里不一，二就是表里不一」（00:23:52）。所谓不一致，不出此二端：所说非所想，所现非所是。

接收者亦复不一致。对面之 George 连称「对不起，我没听懂」，而同时屏息、伸双手、呜咽出声（00:23:52）。口言不懂，身已示怯；他其实听懂了，听懂的是「她要骂我」，故取防御与躲避之姿。治疗师于此介入，问其当下之所感，George 乃言「我的胃很紧，很不舒服」，并自承早知妻在生气（00:25:33）——知而不言，是第三重不一致。

直问则下不去。若径问「你为何回缩？你为何害怕？」——他本已惧，惧中不能自陈其惧。崔老师于此拈出本讲最要之一语：🟢 崔老师说：「我管这个叫什么呢？叫迂回作战或者是曲线救国」（00:27:44）。其路径有四节：自其外显之表现出发，向下寻一类同之物；由此类同之物，下探其可一致之深层结构；复自深层结构，迂回至其内心之真实想要（00:28:14）。本欲于原处直搭一桥而搭不进，便绕行一圈——圈虽远，所至者同。

其类同之物常是身体之微相：耸了一下肩、低了一下头、呼吸有些急促。由是遂起一疑：此算不算读心术？崔老师断之曰：🟢 崔老师说：「这个东西算不算叫读心术呢？我觉得不算……它应该是属于我们反馈给了客户一个现实的表征情况」（00:29:24）。读心是代断其心，此则只报其所见——我看见你如此，其背后是何，仍由客户自答。所报者是观察，所得者是线索；线索积而底层之貌自现。

复有一序不可乱：须先走完其稳态机制，令客户识别并看清自身之标准沟通模式，而后可言改变。若上来便令其改，崔老师戒之曰「这个步子有点太大」（00:30:07）。先陪其具身化、先模仿、先走一遍，待其自见，改造方有着落。

四改造的是系统，不是某一个要素

第一阶段之要为二：使客户于信任安全中进入创造体验之境，并令其锚定于期望状态——崔老师特诫，富足之家庭系统往往分分钟跌回旧态，故必锚之于期望，再具身化地带回当下（00:31:11）。

由是入第二部分：改造。崔老师谓此是核心关键环节——不能只陪客户识别，还须为之调整（00:32:34）。而其第一义，仍是系统之眼。

🟢 崔老师说：「我们在这里面要改造的是系统，改造的一定不是某一个要素」（00:33:22）。常见之误，是见问题似在妈妈身上，便径去调整妈妈；此路不通。崔老师明其递变之序：要素之改变，改变关联关系；关联关系改变，目的随之而改；目的既改，系统乃改（00:34:21）。是故改一人不能改一家，除非该要素之离去本身已使结构解体——死、离、子远游，则关联关系自变，系统自迁，然此非咨询师之功，乃系统之自然流变。故崔老师特立二前提：其一，系统整体未变，家庭尚在、未破碎；其二，要素之关联关系皆在（00:34:21）。二前提不具，则所论非改造，而是重组。

其法，崔老师以一喻尽之：🟢 崔老师说：「原来啊，各家庭成员各自为政，就好像是你要去包个饺子，你要去和馅儿……原来这个葱花是葱花，肉是肉，韭菜是韭菜，鸡蛋是鸡蛋，你现在需要做的事情是在和馅儿的过程当中，把这些所有的元素给它搅和到一起，放到一个馅儿盆里」（00:35:06）。此喻之精，在「各为其是」四字。未和之前，每一味皆自持其味，互不相干，亦互不相犯；既和之后，彼此交融而生冲突，冲突之中乃有新味。治疗师所搅和而出者，不是妥协，而是共性的价值观——情感、隐私、尊重、信任（00:35:06）。价值观一立，系统之能量整体上提，改变遂有其源。

若搅之不动，则尚有末一途：治疗师自为 modeling，令客户模仿己，或模仿他人（00:36:24）。示范亦是干预，然其位在「可供参照」，不在「应当如此」。

五软性措辞与二位置换视角

理论的尽头是分寸。崔老师取书一百一十四页 Fred 与 Mary 之案例，令课堂逐句读其对白，而于措辞处三致意焉。

其一，软性措辞。治疗师谓 Fred：「我好像听到你说的话，是你想让 Mary 更关心你；我还注意到你的语音语调和姿势手势，好像和你说的不太一样。」崔老师特辨「不一样」之说法——不要说「我认为这个地方不一样」，而要说「好像」「我感觉似乎」（00:37:47）。其法出自《催眠天书》之四绝并进：主语换成我，加上「我感觉」，再加一个模棱两可的「似乎」（00:38:45）。三法叠加之效，是既已给出结论，而不强求客户认同。客户认之，则顺势而入；客户不认，则「这也只是我的一种感觉」，退路自在。崔老师郑重点出此非小节：🟢 崔老师说：「如果你的客户是你不熟悉的，或者说这个客户真的是有点精神疾病的，你要是给他下一个特别严重的结论，他是不会惯着你的」（00:40:04）。

其二，不擅揣测。治疗师问「你是感觉到有一些无助吗」，课堂上遂起一疑：此「无助」是客户的，还是咨询师的？崔老师断此为节录之故，谓客户此前必尝自道 helpless 之类的感受，故不宜擅自揣测客户所用者是何种感受，只作回放、反馈、回溯即可（00:40:59）。教练可以递词，不可以代心。

其三，二位置换视角。治疗师谓 Fred：「你把我当做是你，假设你自己就是 Mary」——崔老师点明，此即具身化之二位置换视角，班德勒与葛瑞德换得极直接（00:42:16）。令发送信号者亲入接收者之位，两次沟通并列而观，其「为何愈走愈远」遂不待解说而自见。转至一百一十七页，治疗师问 Mary：「他在跟你说话的时候，你真正看到了、听到了、感受到了一些什么呢？」——此是调取感官通道、探索内在 VAK（00:43:25）。Mary 答「他会再次批评我，对他而言我总是不够感性」，崔老师即指其为一般化：旧日之沟通模式积而成一般化，一般化一生 bug，过去之事虽已过去，而其影响及于未来（00:44:01）。

复合等同之拆解，至末段而至其极。Mary 谓夫之表情即等于「他受够了我、我不够好」，治疗师层层追问其所以，末乃问曰：🟢 崔老师说：「那如果他露出这种表情，有没有可能会告诉你，他是想去厕所了呢？那意味着他也是觉得你有错吗？」（00:51:17）Mary 答「那好像不是」。一问而等同解。表情不必然是责备，正如责备不必然是表情；等同既破，则 Mary 之自施其压亦无所附丽——崔老师谓其「只是用他的这种样子来给自己施压」（00:51:17）。全讲遂止于此。

七体系连接

与 D17 之承接。上一讲立「不要主动去晃其筛」，谓信息当自流、自滤、自留。本讲之复合等同正承其绪：既已滤得线索，而客户于某处下不去，则不可以问强压之，只可绕行。彼言其守，此言其进；彼戒强求，此示曲致。二讲合观，「不晃」与「迂回」实是一事之两面。

与表征系统之连接。本讲所谓语言与体验之连接，即表层结构与深层结构之贯通，其学理归属在语义学之后设模式。删减、扭曲、一般化三者，正是《神奇的结构》所立之后设模式之 violaions；十月七点档讲《神奇的结构 二》，即是此线之延展。

与系统论之连接。要素—关联关系—目的—系统之递变，是本课程三条主线中「系统论」一支之主干。崔老师明言，此正是学完萨提亚而转向系统论之故：家庭之中改一人不可改，必人人皆改（00:33:22）。和馅儿之喻，即系统涌现（emergence）之白话说法——整体之味，不在任何一味之中。

与 ICF 之接口。期望状态之锚定对应核心能力三之「建立协议」与目标设定；「教练引导的方向是朝向客户的理想」对应核心能力五与伦理守则中「客户议程优先」之条；软性措辞之「我感觉似乎」则直指核心能力五之「保持中正」——教练给其所见而不执其所见。

八今日一问 · 考据

一问：desired state 与 desired outcome 之别，原书是否明文？ 崔老师前讲已辨 outcome 是点、state 是场，本讲复与 ICF 之成果导向对举。萨提亚原书第一百页以下用 desirable state 抑或 outcome，宜复核原文。

二问：「create mood」当作何字？ 转写作 create mood（00:20:27、00:21:34），然据上下文「创造一种模式或者创造的模型」及 create mode（00:21:34），疑当作 create mode（创造新模式），mood 为 ASR 之讹。待证。

三问：Fred 与 Mary 案例之页码。课堂依次举一百一十四、一百一十七、一百一十九页（00:37:47、00:43:25、00:46:11），与今通行本页码是否相合，宜比对。

四问：凌波微步之维数说。八点场崔老师以金庸凌波微步为升维之喻，谓「在四维或五维空间中打三维的小罐」。此是崔老师之读法，金庸原书无此义，当标为课堂原创。

转写疑误：「谓指名动词」（00:11:27）当作谓词与名物化动词（predicates 与 nominalizations）；「米歇尔 / 乔治」转写或作 Michelle / George，原书拼法待核；「mr」（00:45:21）疑为 misunderstanding 之截略。「大玉儿」「于飞老师」为课堂学员称谓，非书中人物。
